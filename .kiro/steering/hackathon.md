# Hackathon Constraints - Ready, Spec, Ship

**Sponsor:** Kiro
**Host:** Trivial Business Limited
**Submission deadline:** 23 August 2026, 23:59 UTC
**Requirement:** Project must be built entirely from scratch during the competition period.

## Non-Negotiable Submission Rules

Apply these to every decision made in this project:

1. **`.kiro/` lives at repo root and must never be added to `.gitignore`.**
2. **No real personal data, no real invoices, no real credentials anywhere in the repo.**
3. **A seeded demo user with synthetic invoices must always work.**
4. **README must explain:** how Kiro was used, setup instructions, usage instructions, costs, rate limits, testing instructions, and test credentials.
5. **Every third-party library, API, dataset, and asset needs attribution.**
6. **The deployed demo must be free for judges to use.**
7. **Prefer scope cuts over unfinished features.** Ship less, but ship it working.
